---
description: ビルド・テスト実行とエラー修正を自動でループさせる（テスト駆動開発）
---
ユーザーの現在の変更箇所や指定されたコードに対して、ビルドおよびテスト（`npm run test` や `pytest` など、プロジェクトに応じたコマンド）をターミナルで実行してください。
`// turbo-all` アノテーションを利用し、エラーが発生した場合はそのターミナル出力を読み取って原因を分析・修正し、テストが完全にグリーン（成功）になるまで自動でリトライとコード修正を繰り返してください。
テストが成功した時点で、具体的な修正内容とともにユーザーへ完了報告を行ってください。
