# Willoop 分析・マッチング プロンプト総合ガイド

本ディレクトリ（`prompts/`）には、Willoopシステムにおける「学生向け診断結果分析」および「企業向けマッチポイント解説」を実現するためのプロダクション用プロンプト群が格納されています。

---

## 1. ファイル構成と役割一覧

| ファイル名 | 対象ユーザー / 画面 | 主な役割・生成内容 | 主な利用形式 |
| :--- | :--- | :--- | :--- |
| **`personality_analysis_prompt.md`** | 学生・求職者<br>（パーソナリティタブ） | タイプ名、性格傾向、個性、★強み3点、💡向き合い方2点、🚩活きる環境3点 | JSON / Markdown |
| **`value_analysis_prompt.md`** | 学生・求職者<br>（バリュータブ） | ★大切にする価値観、バリュー傾向、★大切にしていること（要約文）、🚩活きる環境3点 | JSON / Markdown |
| **`integrated_analysis_prompt.md`** | 学生・求職者<br>（両タブ一括API） | 上記パーソナリティとバリューを**1回のLLM呼び出し**で同時に生成する統合版 | 統合JSON |
| **`company_match_point_prompt.md`** | 企業担当者・面接官<br>（企業マイページ推薦枠） | 推薦ハイライト、①価値観の共鳴、②現場親和性（同質/補完）、③関わり方処方箋・面談質問2選 | JSON / Markdown |
| **`student_company_match_prompt.md`** | 学生・求職者<br>（おすすめ企業・求人詳細） | おすすめハイライト、①価値観の共鳴、②あなたの強みが活きる現場、③働きやすさ・おすすめ逆質問 | JSON / Markdown |

## 2. 学生側画面（recruit.willoop.net）の表示スロット対応表

学生側UIの各スロットと、プロンプト出力JSONのキーは**1対1で完全一致**しています。

```
┌──────────────────────────────────────────────┐
│ 【パーソナリティタブ】                        │
│ 1. タイプ名               (type_name)         │
│ 2. あなたの性格の傾向     (type_summary)      │
│ 3. このタイプの中での個性 (individual_unique) │
│ 4. ★ あなたの強み（3点）  (strengths)         │
│ 5. 💡 これからの向き合い方(future_orient)     │
│ 6. 🚩 あなたが活きる環境  (ideal_environments)│
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│ 【バリュータブ】                              │
│ 1. ★ あなたが大切にする価値観(top_4_values)   │
│ 2. あなたのバリューの傾向 (value_summary)     │
│ 3. ★ あなたが大切にしていること(core_value)   │
│ 4. 🚩 あなたが活きる環境・企業(ideal_environ)  │
└──────────────────────────────────────────────┘
```

### 2つの「活きる環境・企業」の書き分けルール
パーソナリティ側とバリュー側の両方に「活きる環境・企業」が配置されています。受検者の混乱を防ぎ解像度を高めるため、以下の通り明確に観点を分離しています。

* **パーソナリティ側**: **「どう働くと力が出るか」**
  - 任され方（裁量、指示の具体度）
  - 仕事のペース・変化の量（スピード、新規性、ルーティン）
  - チーム内の役割・上司の関わり方（牽引役、守りの要、補完関係）
* **バリュー側**: **「何を大切にする会社か」**
  - 企業理念・パーパスへの共感
  - 社風・評価カルチャー（本質成果評価、加点主義、心理的安全性）
  - 事業の社会的意義・顧客貢献のあり方

## 3. 企業マイページ側との「鏡合わせ（表裏一体）」マッピング

学生向け診断結果画面と、企業マイページの推薦・マッチポイント解説は、**全く同一の組織心理ロジック・語彙**で表裏一体に対応しています。

```
【学生が見る画面（Willoop診断結果）】
┌───────────────────────────────────────────────────────────┐
│ [パーソナリティ]                                          │
│ 🚩 あなたが活きる環境: 「目的だけ共有して進め方を任せるチーム」   │
│ 💡 これからの向き合い方: 「着実なパートナーとの連携」            │
├───────────────────────────────────────────────────────────┤
│ [バリュー]                                                │
│ 🚩 あなたが活きる企業: 「本質的な成果を正当に評価するカルチャー」 │
└───────────────────────────────────────────────────────────┘
                             ↕ 完全一致（鏡合わせ）
【企業が見る画面（企業マイページ推薦枠）】
┌───────────────────────────────────────────────────────────┐
│ ① 価値観の共鳴: 「貴社の理念と学生の『本質志向』が深く一致」      │
│ ② 現場親和性:   「自律的に前進し、既存チームの突破口となる牽引役」│
│ ③ 関わり方処方箋:「細かな指示よりミッションと裁量を渡すと最大化」 │
└───────────────────────────────────────────────────────────┘
```

| 企業側項目（`company_match_point_prompt.md`） | 学生側対応スロット | 視点・論点 |
| :--- | :--- | :--- |
| **① 価値観の共鳴ポイント** | 【バリュー】<br>・🚩 活きる環境・企業<br>・★ 大切にしていること | **何を大切にする会社か**<br>（理念・社風・評価軸の一致による長期エンゲージメント） |
| **② 現場・チームとの親和性** | 【パーソナリティ】<br>・ⓘ このタイプの中での個性<br>・🚩 活きる環境（役割） | **どう働くと力が出るか**<br>（チーム内立ち位置、同質即戦力または補完バランサー） |
| **③ 活躍を引き出す関わり方** | 【パーソナリティ】<br>・🚩 活きる環境（任され方）<br>・💡 これからの向き合い方 | **どんなマネジメントだと伸びるか**<br>（裁量の渡し方、指示粒度、つまずき防止策） |

### 【双方向マッチング（企業視点 ↔ 学生視点）の鏡合わせ】
企業の推薦文（`company_match_point_prompt.md`）と、学生向け企業マッチ理由（`student_company_match_prompt.md`）は完全に1対1で対応しています：

| 項目 | 学生が見る企業マッチ理由（`student_company_match`） | 企業が見る学生推薦（`company_match_point`） |
| :--- | :--- | :--- |
| **ハイライト** | **💡 おすすめハイライト**（背中を押すキャッチコピー） | **💡 推薦ハイライト**（会ってみたいと思わせるフック） |
| **① バリュー** | **1. 価値観の共鳴**（なぜこの会社に共感でき居心地が良いか） | **1. 価値観の共鳴**（なぜ理念に共感し早期離職がないか） |
| **② パーソナリティ** | **2. あなたの強みが活きる現場**（自分の役割・活躍イメージ） | **2. 現場親和性**（同質即戦力 or 補完突破口としての機能） |
| **③ マネジメント** | **3. あなたが伸び伸び働ける環境** ＆ おすすめ逆質問 | **3. 活躍を引き出す関わり方** ＆ おすすめ面接質問2選 |

## 4. システム連携（API呼び出し）パターン

### パターンA: 統合一括呼び出し（推奨・標準）
- 使用プロンプト: **`integrated_analysis_prompt.md`**
- 特徴: 1回のリクエストで、学生画面に必要な全データ（パーソナリティタブ＋バリュータブ）を統合JSONで返却。LLM呼び出しコストとレイテンシを半減できます。

### パターンB: 個別タブ単体呼び出し（非同期・段階読み込み用）
- 使用プロンプト: **`personality_analysis_prompt.md`** / **`value_analysis_prompt.md`**
- 特徴: タブごとに独立してストリーミング生成したい場合や、片方のみ再生成したい場合に利用します。

### パターンC: 企業向けマッチング生成
- 使用プロンプト: **`company_match_point_prompt.md`**
- 特徴: 企業の「設定バリュー・社風メモ」と、学生の「診断結果」を渡し、企業専用の推薦テキストと面接質問2選を生成します。

### パターンD: 学生向け企業マッチ理由生成（双方向マッチング）
- 使用プロンプト: **`student_company_match_prompt.md`**
- 特徴: 学生の「診断結果」と、閲覧中企業の「設定バリュー・社風」を渡し、学生向けのおすすめ理由とカジュアル面談用逆質問を生成します。

## 5. 入力データ仕様（プロンプトに渡すJSON）

### ① 学生向け診断結果出力用 Payload
基本の4特性偏差値に加え、**「設問レベルの突出値（Score 5やScore 1等）」**を含めることで、同タイプ内での画一化（金太郎飴化）を完全に防ぎ、個人のリアルな行動癖を反映させることができます（設問文そのものの直接引用は不要）。

```json
{
  "user_id": "candidate:26",
  "personality": {
    "trait_t_scores": {
      "社交性": 57.8,
      "好奇心": 67.7,
      "不安耐性": 66.3,
      "着実性": 46.2
    },
    "diagnosis_result": {
      "base_type": "推進タイプ",
      "full_name": "周囲を牽引し構想を現実する推進タイプ",
      "is_special": false
    },
    /* 設問レベルの突出傾向（任意・解像度向上用） */
    "highlight_questions": [
      {"q_no": 6, "text": "初めて一緒に働く人とも、すぐに仲良くなれる。", "score": 5},
      {"q_no": 12, "text": "今までにやったことのない仕事をするとき、ワクワクする。", "score": 5},
      {"q_no": 20, "text": "締め切りの間際などプレッシャーのかかる場面でも、冷静さを保てる。", "score": 5}
    ]
  },
  "values": {
    "最上位": [
      {"name": "広い視野", "desc": "広い視野を持つ"},
      {"name": "本質志向", "desc": "本質志向である"},
      {"name": "自己受容", "desc": "自己受容している"},
      {"name": "心身の充足", "desc": "心身ともに健康で満たされている"}
    ],
    "高": [
      {"name": "計画性", "desc": "計画的に進める"},
      {"name": "目標達成", "desc": "目標・目的を達成する"}
    ],
    "最下位": [
      {"name": "上品さ", "desc": "上品に振る舞う"},
      {"name": "一生懸命", "desc": "何事にも一生懸命で全力を尽くす"}
    ]
  }
}
```

### ② 画一化（金太郎飴化）防止の4大メカニズム
1. **特性スコアの凹凸・ギャップに着目**: 「最高値と最低値の差」から、同じ推進タイプでも「アイデア突破先行型」か「手堅い計画完遂型」かを明確に描き分ける。
2. **設問レベルの尖りの反映**: 設問回答の突出項目から微細な行動スタイル（サブファクター）を拾い上げる。
3. **P × V の化学反応**: 行動様式（性格）と内発的動機（価値観）の調和・ギャップから独自のストーリーを紡ぐ。
4. **抽象的一般論の禁止**: 「高いコミュ力」「強い責任感」などの汎用テンプレート表現を禁止し、具体的シチュエーションでの行動を描写する。

## 6. 判定ロジック・知識ベース（全プロンプト共通基準）

### ① パーソナリティ 4クラスター中心値（偏差値空間）
- **安定タイプ**: [社交性 46.1, 好奇心 44.0, 不安耐性 56.1, 着実性 47.5]
- **慎重タイプ**: [社交性 39.3, 好奇心 40.1, 不安耐性 40.8, 着実性 49.9]
- **巻き込みタイプ**: [社交性 57.7, 好奇心 56.3, 不安耐性 45.9, 着実性 42.2]
- **推進タイプ**: [社交性 56.0, 好奇心 58.6, 不安耐性 55.6, 着実性 59.5]
- **特殊型**: 最短距離 $D_{min} \ge 2.40$ または いずれかの特性との偏差値差が $\pm 20$ 以上の場合。

### ② バリュー42カードの7大志向性クラスタ
全プロンプトで以下の42カード分類に完全準拠しています。

1. **革新・変革志向（5枚）**: 変革、独創性、好奇心、主体性、夢中
2. **達成・成果志向（5枚）**: 目標達成、スピード、効率、一生懸命、ミスを取り戻す
3. **協調・関係志向（8枚）**: 協力、人の尊重、信頼構築、感謝、質の高い対話、顧客への思いやり、愛、情報共有
4. **自律・柔軟志向（5枚）**: 自由、自律、信念、本質志向、広い視野
5. **安定・規律・品質志向（8枚）**: 計画性、秩序、丁寧さ、誠実、上品さ、現実主義、自責思考、謙虚
6. **ウェルビーイング志向（7枚）**: 働きやすさ、心身の充足、自己受容、適度さ、寛容、多様性、ポジティブ
7. **社会性・倫理志向（4枚）**: 社会貢献、社会的責任、公平、自然への配慮

## 7. プロンプト運用・改修ルール

1. **規約バックアップの遵守**:
   - プロンプトファイルを編集する際は、必ず事前にタイムスタンプ付きバックアップ（例: `xxx.YYYYMMDD_HHMMSS.bak`）を作成すること。
2. **表裏一体の同期**:
   - 学生側プロンプトの構成や語彙を変更した場合は、必ず `company_match_point_prompt.md` 側の企業向け推薦プロンプトとの鏡合わせ整合性を確認し、同時にアップデートすること。
3. **統合版（integrated）の完全一致**:
   - `personality_analysis_prompt.md` や `value_analysis_prompt.md` を改修した際は、`integrated_analysis_prompt.md` 内のスキーマおよび判定文も完全に同期させること。
