# Willoop 個人・企業のカルチャー重心ポジショニングマップ仕様書

本ドキュメントは、個々のバリューカードの分類にとどまらず、**「ある個人（または企業）がカルチャー全体の中でどこに位置しているか」**をひと目で直感把握するための**2軸カルチャーポジショニングマップ**の設計仕様書です。

---

## 1. 2軸カルチャーマップの4象限ゾーン定義

個人の重視バリュー（最上位・高）から重心座標 $(X, Y)$ を算出し、以下の4つの象限ゾーン（カルチャータイプ）に分類します。

```
                    【挑戦・変革・柔軟（上）】
                               ▲
                               │
       🚀 変革・開拓タイプ      │       💡 共創・自律タイプ
      （Pioneer / 革新突破）   │      （Creator / 自由・本質）
    ・変革、目標達成、スピード │    ・自由、本質志向、広い視野
    ・新規事業、ベンチャー     │    ・心理的安全性、フラット組織
                               │
 ◀─────────────────────────────┼─────────────────────────────▶
 【成果・タスク重視（左）】    │       【人・関係・チーム重視（右）】
                               │
       🛡️ 堅実・品質タイプ      │       🤝 協調・共感タイプ
      （Guardian / 守護・完遂） │      （Supporter / 調和・信頼）
    ・計画性、秩序、現実主義   │    ・人の尊重、感謝、信頼構築
    ・品質管理、堅実な運営     │    ・温かい風土、ホスピタリティ
                               │
                               ▼
                    【着実・安定・規律（下）】
```

---

## 2. 4つのカルチャータイプの特徴

| 象限 | カルチャータイプ名 | 重心の位置 | 象徴するキーワード | 活躍しやすい環境 |
| :---: | :--- | :---: | :--- | :--- |
| **左上** | **🚀 変革・開拓タイプ**<br>(Pioneer) | 挑戦・変革 $\times$ 成果・タスク | スピード、突破力、結果コミット、前例打破 | 新規事業、急成長ベンチャー、裁量と結果が連動する環境 |
| **右上** | **💡 共創・自律タイプ**<br>(Creator) | 挑戦・変革 $\times$ 人・チーム | 自由、本質志向、大局観、ウェルビーイング | 心理的安全性が高く、目的共有でアプローチを任されるフラットな組織 |
| **右下** | **🤝 協調・共感タイプ**<br>(Supporter) | 着実・安定 $\times$ 人・チーム | 人の尊重、感謝、信頼構築、丁寧さ、対話 | メンバーや顧客を深く大切にする家族的・温かい社風、サービス業 |
| **左下** | **🛡️ 堅実・品質タイプ**<br>(Guardian) | 着実・安定 $\times$ 成果・タスク | 計画性、秩序、誠実、現実主義、品質管理 | ミスが許されない社会インフラ、金融、品質重視の老舗・大企業 |

## 3. 重心座標（ポジショニング）の算出アルゴリズム

個人の回答データ（最上位4枚・高2枚）のカード固有座標 $(x_i, y_i)$ から、加重平均によって個人の重心 $(X_{user}, Y_{user})$ を算出します。

$$X_{user} = \frac{\sum_{i=1}^{6} w_i \cdot x_i}{\sum_{i=1}^{6} w_i}, \quad Y_{user} = \frac{\sum_{i=1}^{6} w_i \cdot y_i}{\sum_{i=1}^{6} w_i}$$

- **重み付け $w_i$**:
  - 最上位カード（4枚）: $w = 2.0$
  - 高カード（2枚）: $w = 1.0$

企業の組織バリューに対しても全く同一の計算を行うことで、企業座標 $(X_{company}, Y_{company})$ が定まります。

## 4. マッチング画面でのビジュアル表示効果

学生画面や企業マイページにおいて、2つの点を同一マップ上にプロットします。

1. **同質フィット（距離が近い）**:
   - 2つのピンがほぼ重なる $\rightarrow$ 「価値観がぴったり一致！自然体で馴染める環境」
2. **補完フィット（同一の横軸で、縦軸が上下に位置）**:
   - 例: 企業が「協調・共感（右下）」で、学生が「共創・自律（右上）」
   - $\rightarrow$ 「人・関係を大切にする土台は同じ。穏やかなチームに突破力を届ける最高の推進エンジン」
